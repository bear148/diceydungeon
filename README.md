# DiceyDungeons
<img src="icon.webp" width="20%">

Open-source clicker dungeon roguelike type of game. Easy to play, permadeath, and fully RNG based. You can collect spells and set the numbers of your die to specific attacks, allowing for full customizability of your playstyle.

Expect more content to arrive soon.
